A responsive, BMI (Body Mass Index) calculator built with vanilla HTML, CSS, and JavaScript. Supports both metric and imperial units, displays a visual BMI scale, and provides personalized healthy weight range information.
Here's your BMI Calculator — a index.html , bmi.html, a script.js and a sheet.css file with everything built in. Here's what it includes:
Features:
  

Metric & Imperial unit toggle (kg/cm)
BMI calculation with result
Ideal weight range based on your height
Weight difference from the midpoint of the healthy range
Input validation with error messaging
Press Enter to calculate and show the result in bmi.html page
